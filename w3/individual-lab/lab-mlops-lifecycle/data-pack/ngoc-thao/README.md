# HƯỚNG DẪN VẬN HÀNH LUỒNG LIFECYCLE (README.md)

Để khởi chạy toàn bộ luồng phát hiện dịch chuyển và tái huấn luyện mô hình từ đầu đến cuối, người vận hành cần di chuyển vào thư mục giải pháp (`cd data-pack/ngoc-thao`), thiết lập cấu hình biến môi trường trỏ đến máy chủ trung tâm thông qua lệnh `$env:MLFLOW_TRACKING_URI="http://localhost:5000"`, sau đó thực hiện đăng ký mô hình nền móng v1 bằng lệnh `uv run --python 3.11 --no-project --with "mlflow==2.13.2" --with scikit-learn --with pandas --with numpy python pipeline.py --data ../data/baseline.csv`, và cuối cùng kích hoạt bộ điều phối MLOps Lifecycle bằng cách thực thi lệnh `uv run --python 3.11 --no-project --with "mlflow==2.13.2" --with "evidently==0.4.20" --with scikit-learn --with pandas --with numpy --with fastapi --with uvicorn --with prometheus_client --with requests python retrain.py --reference ../data/baseline.csv --current ../data/drifted.csv --holdout ../data/holdout.csv --post-deploy-eval ../data/post_deploy_eval.csv`, rồi tiến hành nhập ký tự `y` tại cổng phê duyệt thủ công (Approval Gate) để thăng cấp mô hình v19 lên môi trường production live, tự động kích hoạt 24 chu kỳ giám sát hậu triển khai và đồng bộ toàn bộ dữ liệu chỉ số hiệu năng trực quan lên Grafana Dashboard tại địa chỉ `http://localhost:3000`.
